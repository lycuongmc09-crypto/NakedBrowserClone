# Naked Browser (Clone)

Ultra-lightweight, zero-bloat, privacy and high-speed Android web browser.

### Đặc điểm:
- **Dung lượng APK**: Siêu nhẹ (< 1MB) nhờ loại bỏ các thư viện UI nặng nề (pure Native Android SDK).
- **Multi-Tab**: Mở vô hạn Tab, chuyển đổi tức thì không giật.
- **Undo Closed Tab**: Nhấn giữ nút `+` để khôi phục tab vừa đóng.
- **Desktop Mode**: Chuyển User-Agent sang Desktop bằng 1 chạm (`D`).
- **Privacy & Security**: Nút dọn dẹp Cache & Cookies, xóa sạch khi đóng app (`Exit`).
- **GitHub Actions**: Tự động build APK trên cloud.
